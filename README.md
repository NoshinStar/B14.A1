# DevConf 2026 – Conference Landing Page

## ✨ Overview

This project is a responsive landing page built for a fictional developer conference, **DevConf 2026**. It was developed as part of an AI-assisted frontend assignment, where the core page was extended by prompting an AI coding assistant to build a new, fully-styled section that matches the existing design system.

The `prompts.md` file in this repository documents the exact prompt used to generate the **Hackathon Track** section, showcasing practical AI-prompting and code-review skills alongside frontend development.

## 🌐 Live Demo

🔗 https://noshinstar.github.io/B14.A1/


## 🌟 Main Features

- **Responsive Navbar** — Logo, nav links, and a call-to-action button
- **Hero Section** — Headline, description, and a "Register Now" CTA
- **Speakers Grid** — Featured speaker cards with photo, track tag, name, and role
- **Pricing Plans** — Standard, Pro, and Team tiers with feature comparisons
- **Hackathon Track Section** *(AI-prompted addition)* — Dark navy themed section with prize pool, duration, and team-size stat boxes plus a registration CTA
- **Footer** — Logo, social links, and copyright

## 🛠️ Technologies Used

- **HTML5** — Page structure and semantic markup
- **CSS3** — Styling, layout, and the dark-themed Hackathon section

## 📦 Dependencies

This is a vanilla HTML/CSS project — no external libraries or frameworks are required.

## 🚀 Getting Started

### 1. Clone the Repository

```
git clone https://github.com/NoshinStar/B14.A1.git
```

### 2. Navigate to the Project Directory

```
cd B14.A1
```

### 3. Run the Project

Open `index.html` directly in your browser (Chrome, Firefox, or Edge), or use **VS Code with the Live Server extension** for the best experience.
